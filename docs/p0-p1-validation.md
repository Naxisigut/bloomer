## 自动化验证

以下命令在 `apps/agent` 执行，均通过：

```sh
go vet ./...
go test ./...
go test -race ./...
make build
```

覆盖的关键边界：

- 配置相对路径、用户目录展开、严格 JSON、无效监听和 URL、令牌权限、生成与重启复用、符号链接拒绝。
- 日志单文件 5,000,000 字节、最多 10 个文件（50 MB）、轮转及旧备份 14 天清理、敏感属性脱敏。
- SQLite WAL / FULL / foreign_keys / busy_timeout，单写与双读连接；连接替换后仍保持只读约束。
- 复合账户/记录唯一键；事务中途失败时收益和成功检查点一起回滚；取消不提交。
- 首次迁移失败时 DDL 和版本全部回滚，之后可重试；旧版升级前一致备份、失败回滚、再次成功升级。
- 高版本拒绝、已应用 SQL 校验和不一致拒绝、外来未版本化非空数据库拒绝。
- 一致备份包含未 checkpoint 的已提交 WAL 数据，恢复后明细和维护时间一致，备份不覆盖现有文件。
- 独立子进程无法取得同一文件锁；退出后遗留锁文件不阻碍重启。
- 健康接口认证、Origin 拒绝、统一错误、离线状态、数据库失败明确 503 且不泄露 SQL。
- 实测脱敏结构，3/4/5/6 位小数秒、UTC 偏移归一化、大整数 ID、负金额、零 Token、重复折叠、冲突失败、缺失/null、溢出、重复 JSON 成员、错误时间和过大响应。

OpenAPI 已通过 YAML 语法及所有本地 `$ref` 引用解析检查。当前是草案，收益接口的完整请求/响应与行为一致性在 P4 验收。

## 实际进程验证

在仓库根目录运行：

```sh
python3 scripts/smoke-agent.py
```

使用临时数据和日志目录、回环随机端口、**不存在的官方凭证路径**，验证：

1. 无官方网络请求即可启动、自动迁移并生成独立令牌。
2. 未认证返回 401，带独立令牌读取到明确离线健康状态。
3. 第二个真实进程启动失败，不能竞争同一数据库。
4. SIGTERM 正常退出并持久化关闭时间。
5. 重启保留令牌和数据库；SIGKILL 不伪造新的正常关闭时间。
6. 异常退出后再次启动成功，再次正常关闭更新时间。
7. 数据目录 0700，数据库与令牌 0600；日志中不存在访问令牌。

测试通过后自动回收进程与临时目录，没有在真实 Provider 上执行故障演练。系统 Python 的验证连接使用 `mode=rw` 配合 `query_only=ON`，允许关闭后的 WAL 辅助文件重建，同时禁止修改数据。
