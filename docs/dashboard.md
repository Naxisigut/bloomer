# 静态看板架构

更新日期：2026-10-21

独立项目位于 `apps/dashboard`，启动方式与完整说明见[看板 README](../apps/dashboard/README.md)。

## 产品范围

提供五个页面：首页、收益分析、收益明细、我的设备、数据查询。收益默认近 1 天，支持自选日期。所有页面固定使用中国标准时间（Asia/Shanghai，UTC+8），不提供时区切换，也不读取旧的时区偏好。桌面使用侧栏与整行趋势图，窄屏使用顶部导航并调整指标排列。

初次没有设备时进入明确标注的演示模式；有已保存设备时恢复上次选择，首次优先选真实设备。设备失联时保留真实模式并显示错误，不用演示数据掩盖问题。

设备切换、工作状态、温度、内存、近 1 小时收益、近 24 小时收益和余额合并为紧凑的固定顶栏，仅在首页显示。顶栏从左至右分为设备切换、设备状态、收益三个区域；设备名称前以绿色/红色圆点表示采集正常/异常，悬停可查看具体状态。滚动首页时仍可查看。其他页面隐藏整个顶栏。1 / 24 小时采用独立的滚动窗口，汇总所选设备全部模型，不受下方日期、模型或粒度筛选影响；展示 4 位小数，移除滚动窗口辅助文案和可提现金额。本期收益仅在趋势面板内显示。页面保留数据口径和状态提示。侧栏顶部显示 Bloomer，右侧统一提供刷新与连接设备图标按钮。

首页保留设备与收益顶栏，原趋势位置展示固定当天的按小时收益折线图；日期固定为北京时间当天，不提供日期或粒度筛选。默认显示全部收益，可同时选择多个模型，并可叠加全部收益曲线；今日总收益始终统计全部模型，避免多选时重复相加。首页模型选择、查询结果和在途请求独立于其他菜单，切换设备重置选择，每分钟、手动刷新及返回首页时查询当天；跨午夜清除前一天的图表，查询成功后，已过去及当前小时没有收益时显示 0 值点，未来小时保持空白；查询失败继续提示错误，不补为零。曲线使用单调三次插值平滑连接，不产生额外的峰值或低于零的收益；横轴逐小时显示 00:00～23:00，窄屏横向滚动。“收益分析”菜单使用独立的 #analysis 地址，承载历史收益趋势及整组筛选。五个页面均直接显示内容，不再显示单独的页面标题行。收益分析中的日期范围、自选日期、模型和趋势粒度集中在图表上方的独立筛选面板，收益趋势面板仅保留标题、所选时段合计和图表。明细表集中在收益明细页；分析页与明细页分别保存日期、模型、趋势粒度和分页；共享的日期控件移至当前菜单后恢复该菜单自己的选择，两个菜单互不联动，CSV 仅使用明细页筛选。切换菜单时隔离在途请求，防止旧响应覆盖当前页面；设备变化后丢弃旧设备的缓存结果并重置模型。支持全部模型和单个模型；日期 / 粒度改变时保留所选模型，切换设备时重置。快捷范围为近 1 / 7 / 30 天和近一年；按统计时区的日历日期筛选。趋势仅展示收益：1 天按小时，2～30 天按天，超过 30 天可按天或按月，自选日期同样适用。按小时的柱子提示只显示北京时间时分；收益标签跟随悬停或键盘聚焦的柱子，并限制在图表范围内，不显示重复的浏览器原生提示。分组切换重新查询 Agent 的对应统计，不改变收益总额。筛选操作只更新当前菜单对应的数据，不更改其他菜单的选择，也不重查或清空顶栏；顶栏随设备切换、手动刷新及每分钟自动刷新更新，明细翻页暂停时仍独立更新。

明细每页条数支持 1～500 自定义并保存在浏览器，显示总页数，可直接输入目标页跳转。页大小和筛选变化时回到第一页。装饰性按钮 / 指标图标、明细字母头像及重复状态列已移除；窄屏导航和有数据含义的图例、状态指示保留。

我的设备增加最新设备状态与采集时间，展示 CPU、内存、Swap、GPU、温度与热压力、磁盘、进程和模型等已有指标。数据查询提供独立的设备、起止分钟、每页条数及前后翻页；默认近 24 小时，可查看单条完整状态。历史区间固定，不随最新状态的每分钟刷新移动；无记录不补零。设备状态演示提供明确标识的 7 天分钟数据。

我的设备还提供[远程操作](remote-control.md)：本地模型多选切换与开启、官方目录模型下载、Darkbloom 关闭和重启。操作前确认目标，后台执行并展示最近 50 条结果；旧 Agent 提示升级，演示设备只读。

## 实现选择

- 普通静态服务器提供原生 HTML / CSS / JavaScript；无 Node 运行时服务、第三方前端依赖和打包步骤。
- 每分钟及页面从后台返回前台时，按当前菜单刷新设备状态、收益及采集健康；沿用连接、确认、导出和分页暂停规则，历史状态查询区间及收益明细后续页保持不动。设备状态请求期间保留现有显示，响应完成后再判断新样本是否过期，避免旧缓存重绘造成短暂的过期提示。
- 浏览器按所选设备地址携带 Bloomer Bearer 令牌直连既有 `/v1` 查询与控制接口。任务活动和设备收益仍由 schema 5 采集端保存，查询不触发采集。
- 连接统一手动添加或导入，浏览器不读取本机 Agent 文件；远程设备使用已有 Tailscale HTTPS 地址及端口。
- 名称、地址、Bloomer access.token 与选中设备持久保存在浏览器该来源的 localStorage；测试健康成功后才保存。官方 Darkbloom 令牌仅由 Agent 读取；不进入网页、仓库或浏览器。来源隔离和迁移方式见[连接设备指南](connect-device.md)。
- Agent 1.0.7 起允许任意网页来源（`Access-Control-Allow-Origin: *`），无需来源配置。合法 OPTIONS 免令牌，实际 GET/POST 必须认证。预检显式允许 Authorization、Content-Type 和 Accept，不启用跨域 Cookie 凭证，浏览器使用 `credentials: omit`；成功与错误响应都带 CORS 头，原无 Origin 调用不变。
- 请求层保留参数白名单、12 秒超时、取消、8 MB 上限、响应校验及中文错误映射；浏览器不能可靠区分网络/证书/CORS 时给联合排查提示。
- 演示生成和游标均在浏览器执行，保留只读限制；控制确认、幂等编号、失败后核对和后台任务规则不变。
- 每台设备单独切换查询，首版不做跨设备收益合并，避免同一账户重复统计。
- 首页使用独立的当天按小时统计和当天模型列表，选中模型分别请求同一时间边界的小时统计，按模型显示多条折线。所有曲线共用 Y 轴，按所选数据范围生成 1 / 2 / 5 × 10ⁿ 的规整金额间隔；刻度以整数微美元生成，文字精度跟随间隔，网格线与标注金额一致，小额收益最多显示 6 位小数。悬停或键盘聚焦数据点时，标签仅显示 4 位小数金额，背景和边框与对应曲线同色；时间与模型仍保留在数据点的无障碍描述中。
- 金额以整数微美元计算；统计时区固定以 IANA 名称 Asia/Shanghai 传给 Agent，日期范围遵循中国标准时间日历并转换为 UTC 半开区间。
- 收益分页固定初次查询的时间边界，后续页面保留原筛选与游标。看板按记录偏移缓存游标，从最近的已知位置每次读取最多 500 条定位目标页，不更改 Agent 契约。跳页可取消，失败保留当前页；翻页期间不自动刷新记录。
- CSV 读取全部匹配分页，防重复记录和公式注入；金额精确到 6 位小数。导出时间与页面统一使用北京时间（UTC+8），保留来源小数秒精度并标注 `+08:00`，文件名使用北京时间的筛选开始日期。

## 状态处理

界面分别处理未完成首次采集、连接失败、凭证无效、数据库暂不可用、数据过期、采集关闭、限流等待、历史缺口、查询范围被保留期截断以及清理失败。

空闲状态与收益采集健康分别展示。采集端读取本机任务标志，并通过公开认证公钥精确匹配 Provider ID，查询该设备最新一条收益；无任务处理或排队且收益距采集时严格超过 5 分钟才为空闲。无证据或状态过期显示未知；收益日期、模型和分页筛选不影响此判定。顶栏同时展示本机设备热压力与内存压力，正常为绿色、轻度热压力/内存压力偏高为橙色、较高或严重热压力/严重内存压力为红色。详情与历史保留任务标志、设备收益时间和同步时间。无需网页登录令牌。

余额来自官方账户快照，不受本地留存期限制。本期、近 1 / 24 小时收益和趋势来自所选设备保存的明细；初次导入只能取得最近窗口，空白分组不代表官方零收益。

## 验证与边界

当前变更以本地合成数据验证 CORS、令牌、连接存储、查询、分页、CSV 和模拟控制流程。家中真实 Tailscale HTTPS 联调需更新 Agent后由用户完成，不能将历史真实设备验证视为本次直连架构的生产验证。

本期不增加账号、配对码、会话签发、令牌刷新或中心服务。普通静态托管即可；静态服务器不存储连接信息。运行环境原数据库、历史、Agent 配置及令牌保留。本次不部署远程设备，不执行真实 Darkbloom 控制操作。
