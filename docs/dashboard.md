# 看板第一版

更新日期：2026-10-18

独立项目位于 `apps/dashboard`，启动方式与完整说明见[看板 README](../apps/dashboard/README.md)。

## 产品范围

围绕“赚了多少、来自哪些模型、采集是否正常”提供三个页面：收益概览、收益明细、我的设备。默认最近 30 天、上海时区，支持其他时区和自选日期。桌面使用侧栏与图表并排布局，窄屏折叠导航并调整指标与图表排列。

初次没有设备时进入明确标注的演示模式；有已保存设备时恢复上次选择，首次优先选真实设备。设备失联时保留真实模式并显示错误，不用演示数据掩盖问题。

## 实现选择

- Node.js 内置 HTTP 服务 + 原生 HTML / CSS / JavaScript；无第三方运行依赖和打包步骤。
- 本机服务转发四个既有 Agent 接口，避免 Agent 拒绝浏览器 Origin 带来的跨域问题。
- 本机设备自动发现；远程设备使用用户提供的 Tailscale HTTPS 地址和独立令牌。
- 凭证只保存在本机服务端的私有配置文件；不上传托管平台，不返回浏览器，不进入 Git。
- 每台设备单独切换查询，首版不做跨设备收益合并，避免同一账户重复统计。
- 金额以整数微美元计算；时区通过 IANA 名称传给 Agent，日期范围遵循当地日历并转换为 UTC 半开区间。
- 收益分页固定初次查询的时间边界，后续页面保留原筛选与游标。翻页期间不自动重置记录。
- CSV 读取全部匹配分页，防重复记录和公式注入；金额精确到 6 位小数。

## 状态处理

界面分别处理未完成首次采集、连接失败、凭证无效、数据库暂不可用、数据过期、采集关闭、限流等待、历史缺口、查询范围被保留期截断以及清理失败。

官方账户累计与余额不受本地留存期限制。趋势、模型贡献和本期任务数来自所选设备保存的明细；初次导入只能取得最近窗口，空白分组不代表官方零收益。

## 验证与后续

已通过语法检查与 8 项自动测试，并在浏览器检查时间 / 模型筛选、分页、设备健康详情及连接错误提示。当前环境未配置真实设备，真实 tailnet 联调尚未完成。

第一版不包含看板 DMG、系统登录启动、公开托管、跨设备合并、Provider 物理设备映射、远程控制或资源监控。后续可以根据实际使用决定是否增加。
