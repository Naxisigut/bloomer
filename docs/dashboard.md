# 看板第一版

更新日期：2026-10-19

独立项目位于 `apps/dashboard`，启动方式与完整说明见[看板 README](../apps/dashboard/README.md)。

## 产品范围

提供四个页面：收益分析、收益明细、我的设备、数据查询。收益默认近 1 天，支持自选日期。所有页面固定使用中国标准时间（Asia/Shanghai，UTC+8），不提供时区切换，也不读取旧的时区偏好。桌面使用侧栏与整行趋势图，窄屏使用顶部导航并调整指标排列。

初次没有设备时进入明确标注的演示模式；有已保存设备时恢复上次选择，首次优先选真实设备。设备失联时保留真实模式并显示错误，不用演示数据掩盖问题。

设备切换、当前是否空闲、设备热压力、内存压力、近 1 小时收益、近 24 小时收益和余额合并为紧凑的固定顶栏，仅在首页“收益分析”显示，滚动首页时仍可查看。其他页面隐藏整个顶栏。1 / 24 小时采用独立的滚动窗口，汇总所选设备全部模型，不受下方日期、模型或粒度筛选影响；展示 4 位小数。本期收益仅在趋势面板内显示。页面保留数据口径和状态提示。侧栏顶部显示 Bloomer，右侧统一提供刷新与连接设备图标按钮。

首页以“收益分析”为菜单及浏览器标题，四个页面均直接显示内容，不再显示单独的页面标题行。日期范围、自选日期、模型和趋势粒度集中在图表上方的独立筛选面板，收益趋势面板仅保留标题、所选时段合计和图表。明细表集中在收益明细页；进入明细页时，日期控件移至明细面板并保持筛选状态，模型选择与分析页同步。支持全部模型和单个模型；日期 / 粒度改变时保留所选模型，切换设备时重置。快捷范围为近 1 / 7 / 30 天和近一年；按统计时区的日历日期筛选。趋势仅展示收益：1 天按小时，2～30 天按天，超过 30 天可按天或按月，自选日期同样适用。分组切换重新查询 Agent 的对应统计，不改变收益总额。筛选操作只更新趋势和明细，不重查或清空顶栏；顶栏随设备切换、手动刷新及每分钟自动刷新更新，明细翻页暂停时仍独立更新。

明细每页条数支持 1～500 自定义并保存在浏览器，显示总页数，可直接输入目标页跳转。页大小和筛选变化时回到第一页。装饰性按钮 / 指标图标、明细字母头像及重复状态列已移除；窄屏导航和有数据含义的图例、状态指示保留。

我的设备增加最新设备状态与采集时间，展示 CPU、内存、Swap、GPU、温度与热压力、磁盘、进程和模型等已有指标。数据查询提供独立的设备、起止分钟、每页条数及前后翻页；默认近 24 小时，可查看单条完整状态。历史区间固定，不随最新状态的每分钟刷新移动；无记录不补零。设备状态演示提供明确标识的 7 天分钟数据。

## 实现选择

- Node.js 内置 HTTP 服务 + 原生 HTML / CSS / JavaScript；无第三方运行依赖和打包步骤。
- 本机服务转发六个既有 Agent 接口，包括最新设备状态与历史接口，避免 Agent 拒绝浏览器 Origin 带来的跨域问题。任务活动和该设备最新收益由 schema 5 采集端保存，看板读取本地数据库接口。
- 本机设备自动发现；远程设备使用用户提供的 Tailscale HTTPS 地址和独立令牌。
- 凭证只保存在本机服务端的私有配置文件；不上传托管平台，不返回浏览器，不进入 Git。
- 每台设备单独切换查询，首版不做跨设备收益合并，避免同一账户重复统计。
- 金额以整数微美元计算；统计时区固定以 IANA 名称 Asia/Shanghai 传给 Agent，日期范围遵循中国标准时间日历并转换为 UTC 半开区间。
- 收益分页固定初次查询的时间边界，后续页面保留原筛选与游标。看板按记录偏移缓存游标，从最近的已知位置每次读取最多 500 条定位目标页，不更改 Agent 契约。跳页可取消，失败保留当前页；翻页期间不自动刷新记录。
- CSV 读取全部匹配分页，防重复记录和公式注入；金额精确到 6 位小数。

## 状态处理

界面分别处理未完成首次采集、连接失败、凭证无效、数据库暂不可用、数据过期、采集关闭、限流等待、历史缺口、查询范围被保留期截断以及清理失败。

空闲状态与收益采集健康分别展示。采集端读取本机任务标志，并通过公开认证公钥精确匹配 Provider ID，查询该设备最新一条收益；无任务处理或排队且收益距采集时严格超过 5 分钟才为空闲。无证据或状态过期显示未知；收益日期、模型和分页筛选不影响此判定。顶栏同时展示本机设备热压力与内存压力，正常为绿色、轻度热压力/内存压力偏高为橙色、较高或严重热压力/严重内存压力为红色。详情与历史保留任务标志、设备收益时间和同步时间。无需网页登录令牌。

余额来自官方账户快照，不受本地留存期限制。本期、近 1 / 24 小时收益和趋势来自所选设备保存的明细；初次导入只能取得最近窗口，空白分组不代表官方零收益。

## 验证与后续

收益接口沿用已有真实设备验证。状态新增自动测试覆盖状态与未知值、时间区间、固定范围分页、代理参数白名单及旧 Agent；浏览器检查覆盖顶栏、设备详情、状态明细和分页。已提供设备端采集和迁移实现；真实设备启用需配置官方账户授权并更新采集端。

第一版不包含看板 DMG、系统登录启动、公开托管、跨设备合并、Provider 物理设备映射或远程控制。设备状态仅展示采集端已保存的数据。
